# Firmware assets for the web installer

`manifest-st7789.json` and `manifest-ili9341.json` each write one full 4 MB
image at offset `0x0`. The image contains:

| Range | Purpose |
| --- | --- |
| `0x1000` | Official MicroPython ESP32 OTA build v1.29.0 (4 MB, no PSRAM) |
| `0x310000` | LittleFS image `0xF0000` with `boot.py`, `main.py`, `opendash` |

Files:

| File | Size | Description |
| --- | ---: | --- |
| `OpenDash-MicroPython-st7789-full.bin` | 4 MB | Full ST7789 image |
| `OpenDash-MicroPython-ili9341-full.bin` | 4 MB | Full ILI9341 image |
| `ESP32_GENERIC-OTA-20260824-v1.29.0.bin` | 1.55 MB | Official MicroPython OTA build |
| `opendash-vfs-st7789.bin` | 0.98 MB | LittleFS with ST7789 config |
| `opendash-vfs-ili9341.bin` | 0.98 MB | LittleFS with ILI9341 config |

The MicroPython OTA build has this partition layout:

```text
nvs       0x009000  0x004000
otadata   0x00d000  0x002000
phy_init  0x00f000  0x001000
ota_0     0x010000  0x180000
ota_1     0x190000  0x180000
vfs       0x310000  0x0f0000   (registered dynamically by MicroPython)
```

The VFS images were generated by `tools/build_webflasher.py` using
`littlefs-python`, block size 4096, 240 blocks. They contain `boot.py`,
`main.py` and `opendash/*.py`. The only difference between the two images is
`DISPLAY_DRIVER` in `opendash/config.py`.

The full images were assembled with:

```text
esptool.py --chip esp32 merge_bin \
  -o OpenDash-MicroPython-st7789-full.bin \
  --flash_mode dio --flash_freq 40m --flash_size 4MB \
  0x1000 ESP32_GENERIC-OTA-20260824-v1.29.0.bin \
  0x310000 opendash-vfs-st7789.bin
```

For OTA updates use the official **`.app-bin`** file, not the full `.bin`:

<https://micropython.org/resources/firmware/ESP32_GENERIC-OTA-20260824-v1.29.0.app-bin>
