OpenDash MicroPython 2.1.1-mpy.1

Браузерный установщик OpenDash для ESP32 CYD. Записывает MicroPython с OTA-разделами и сразу добавляет файлы приложения во внутреннюю файловую систему — после установки ничего копировать вручную не нужно.

Установка стирает flash, включая настройки. Выберите ревизию дисплея: ST7789 обычно стоит в CYD «2 USB», ILI9341 — в другой ревизии. Нужен Chrome или Edge на компьютере и USB-кабель с передачей данных.

ST7789

CYD 2 USB, наиболее распространённая

MicroPython ESP32 OTA v1.29.0 + OpenDash с драйвером ST7789 и предзаполненным LittleFS.

Нужен Chrome или Edge на компьютере. Откройте страницу по HTTPS.

ILI9341

ревизия CYD с ILI9341

То же самое, но с драйвером ILI9341. Версия MicroPython и разделы совпадают.

Нужен Chrome или Edge на компьютере. Откройте страницу по HTTPS.

Что происходит при установке

  1. Стирается flash ESP32 (4 MB).
  2. Записывается полный образ 4 MB. В нём по адресу 0x1000 находится официальная сборка MicroPython ESP32 OTA v1.29.0 с двумя OTA-слотами.
  3. По адресу 0x310000 лежит образ LittleFS 0xF0000 с boot.py, main.py и пакетом opendash.
  4. Плата перезагружается и запускает приложение.

Если плата не определяется, зажмите BOOT (GPIO 0), нажмите RESET, отпустите BOOT и снова нажмите кнопку установки.

Обновления

Установленная прошивка поддерживает OTA. Откройте Настройки → Обновление OTA, включите точку доступа, подключитесь к показанной сети и загрузите на странице устройства app-образ .app-bin, например ESP32_GENERIC-OTA-20260824-v1.29.0.app-bin. Полный установочный .bin для OTA не подходит.

Чтобы обновить только Python-файлы без перепрошивки, используйте mpremote; команды есть в README.

Совместимость

  • ESP32-2432S028 «CYD», 4 MB flash, без PSRAM.
  • ST7789 или ILI9341, тач XPT2046.
  • Ninebot G30 / ES4 с BLE; для SHFW — соответствующая прошивка самоката.
  • Аппаратная проверка порта не проводилась; начинайте с безопасного тестового стенда.
