# OpenDash MicroPython

Порт [OpenDash](https://github.com/nope0183/OpenDash) для ESP32 CYD на MicroPython.
Версия порта: **2.1.1-mpy.1**. Верхнеуровневая функциональность и логика
интерфейса повторяют Arduino-версию v2.1.1; код написан заново на MicroPython.

> Проект проверен на хосте (компиляция, криптография, разбор BLE-кадров,
> отрисовка экранов и OTA-запись с подставным разделом). Реальной платы CYD
> и самоката у автора порта не было, поэтому работа дисплея, тача, BLE, ленты
> и OTA на железе остаётся непроверенной. Начинайте с тестового стенда и
> не используйте устройство во время движения.

## Возможности

- Экран телеметрии Ninebot G30 / ES4: скорость, батарея, мощность, поездка,
  одометр, напряжение, ток, температуры, максимальная скорость.
- Три страницы: основной экран, Info и Debug. Переключение свайпом.
- 4 настраиваемые карточки показателей, темы, акценты, яркость, автозатемнение,
  поворот на 180°, блокировка управления во время движения.
- Языки: English и Русский; кириллические шрифты RU1/RU2/RU4.
- Подключение по BLE к самокату через NUS, авторизация Ninebot AES/SHA-1,
  опрос телеметрии, переподключение.
- 12 эффектов ARGB-ленты, три сегмента, настройка цвета HSB, тормозной режим.
- Калибровка резистивного тача, сохранение калибровки и настроек в
  `/opendash.json`.
- OTA через точку доступа ESP32: приём файла MicroPython и запись в следующий
  OTA-раздел через `esp32.Partition`.
- Страница SHFW пока **только для чтения**: редактор 83 регистров, запись и
  резервное копирование в v1 не перенесены.

## Железо

- ESP32-2432S028 «CYD», 4 MB flash, без PSRAM.
- Дисплей ST7789 (ревизия `2 USB`) или ILI9341 — выбирается при установке.
- Резистивный тач XPT2046.
- Ninebot G30 / ES4 с BLE; для расширенных функций — прошивка SHFW.
- USB-кабель с передачей данных.

Распиновка совпадает с upstream:

| Узел | Пины |
| --- | --- |
| TFT | SCK 14, MOSI 13, MISO 12, CS 15, DC 2, BL 21 |
| Touch | CS 33, IRQ 36, CLK 25, MOSI 32, MISO 39 |
| BOOT | GPIO 0 |
| ARGB | GPIO 4, 16, 17, 22, 26, 27 |

## Установка через браузер

Откройте страницу GitHub Pages:

**https://nope0183.github.io/OpenDash-MicroPython/**

Выберите ревизию дисплея и нажмите Install. Установщик:

1. стирает flash;
2. записывает **MicroPython ESP32 OTA v1.29.0**;
3. записывает заранее подготовленный раздел LittleFS с файлами OpenDash.

Нужен Chrome или Edge на компьютере с USB-портом. После установки плата
перезагрузится и запустит OpenDash. Первый запуск может занять несколько
секунд.

> Для OTA нужен именно вариант MicroPython **OTA**: в обычной сборке нет
> второго OTA-раздела. Веб-установщик уже использует OTA-вариант.

### Ручная установка

1. Сотрите flash:
   ```text
   esptool.py --chip esp32 --port COM5 erase_flash
   ```
2. Прошейте MicroPython OTA-сборку для ESP32 (4 MB), файл
   `ESP32_GENERIC-OTA-...bin`, по адресу `0x1000`:
   ```text
   esptool.py --chip esp32 --port COM5 --baud 460800 write_flash -z 0x1000 ESP32_GENERIC-OTA-20260824-v1.29.0.bin
   ```
   Скачать: <https://micropython.org/download/ESP32_GENERIC/> (раздел
   «Support for OTA»).
3. Дайте MicroPython один раз загрузиться, чтобы он создал внутренний
   LittleFS, затем загрузите файлы:
   ```text
   mpremote connect COM5 fs cp -r opendash :
   mpremote connect COM5 fs cp boot.py main.py :
   ```
4. Перезагрузите плату:
   ```text
   mpremote connect COM5 reset
   ```

Если нужен именно готовый образ файловой системы, его можно собрать
`mklittlefs` (размер раздела для OTA-сборки — `0xF0000`, блок 4096, страница
256) или взять из папки `docs/firmware/` в репозитории.

## Управление

- Свайп влево/вправо на главном экране — страницы Main / Info / Debug.
- Шестерёнка — настройки; кнопка «назад» — выход.
- Долгое нажатие на карточку показателя (на главном экране) — выбор виджета.
- В настройках: внешний вид, экран, спидометр, виджеты, язык, калибровка тача,
  ARGB-лента, OTA и SHFW.
- Долгое нажатие на строку «Сброс настроек» сбрасывает конфигурацию.
  Калибровка тача при этом сохраняется.
- BOOT (GPIO 0) отменяет калибровку тача.

## Настройки

Файл `/opendash.json` создаётся автоматически. Он хранит тему, яркость,
единицы, виджеты, язык, калибровку и конфигурацию ленты. Формат — обычный JSON;
если файл повреждён, приложение откатывается к значениям по умолчанию.

## OTA

1. Откройте *Настройки → Обновление OTA* и включите доступ.
2. Подключитесь к сети `OpenDash-XXXXXX` с паролем, показанным на экране.
3. Откройте `http://192.168.4.1/`.
4. Загрузите **app-образ MicroPython** с расширением `.app-bin`, например
   `ESP32_GENERIC-OTA-20260824-v1.29.0.app-bin` со страницы загрузки
   MicroPython. Это не полный `.bin` установщика: полный образ содержит
   загрузчик и таблицу разделов, его нельзя писать в OTA-слот.
5. После сообщения об успехе плата перезагрузится. Не отключайте питание.

OTA-запись использует `esp32.Partition.get_next_update()` и `set_boot()`.
Если OTA-раздела нет (обычная сборка MicroPython), страница покажет ошибку.

## Структура

```text
boot.py                 # частота CPU, gc
main.py                 # запуск приложения
opendash/
  app.py                # связка дисплея, тача, BLE, ленты, OTA
  config.py             # пины и настройки по умолчанию
  display.py            # ST7789/ILI9341 + Canvas
  touch.py              # XPT2046, жесты, калибровка
  ui.py                 # экраны и обработка касаний
  ninebot.py            # BLE, NUS, авторизация, телеметрия
  crypto.py             # AES/SHA-1 Ninebot
  led.py                # эффекты ARGB
  storage.py            # /opendash.json, миграция
  ota.py                # Wi-Fi AP, HTTP, OTA
  fonts.py              # сгенерированные кириллические шрифты
tools/gen_fonts.py      # генератор шрифтов из upstream src/ru_fonts.h
tools/build_webflasher.py # образы LittleFS для веб-установщика
tools/deploy.ps1        # загрузка файлов на плату через mpremote
docs/                   # GitHub Pages: веб-установщик и готовые образы
```

## Разработка

Проверка синтаксиса на хосте:

```text
python -m compileall -q .
```

Хостовые тесты (криптография, BLE-состояние, UI-smoke, OTA-запись) лежат вне
репозитория и используют подставные модули `machine`, `framebuf`, `bluetooth`.
Настоящая проверка требует платы.

## Ограничения

- Нет проверки на физической CYD и Ninebot; возможны отличия в таймингах BLE,
  ориентации тача и поведении конкретной ревизии дисплея.
- Редактор SHFW, запись/бэкап регистров не перенесены.
- Порт использует только внутреннюю файловую систему; SD-карта не нужна.
- Не отключайте питание во время OTA.
